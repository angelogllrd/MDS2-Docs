Bienvenido al repositorio oficial del **Portafolio Digital** de nuestro equipo. Este espacio ha sido creado para centralizar, organizar y documentar todo el trabajo realizado durante el cuatrimestre en la materia **Metodología de Sistemas 2**.

## 🎯 Objetivo del Repositorio

Cumplir con la consigna de la cátedra respecto a la selección y creación de un repositorio de datos estructurado. El objetivo principal es que los docentes y miembros del equipo puedan observar de forma ordenada, clara y sistemática toda la documentación teórica y práctica generada a lo largo del cursado.
